# Chatbot on Custom Chats

An interactive terminal chatbot powered by Google Gemini API (`gemini-3.5-flash-lite`) using conversation history and custom system instructions.

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/kanishk3114S/chatbot_on_customChats.git
   cd chatbot_on_customChats
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Create a `.env` file in the root directory:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. Run the chatbot:
   ```bash
   npm run dev
   ```
   or
   ```bash
   node girl.js
   ```
